Как работает скачивание PDF

Когда вы нажимаете «Скачать PDF», запрос поступает методу download класса JavaLibraryService. Он находит книгу, задаёт имя файла и последовательно передаёт его содержимое браузеру.

От кнопки до файла

  1. Имя книги. Метод берёт название книги и заменяет символы, которые не подходят для имени файла. Кодировка UTF-8 позволяет передать русское название.
  2. Команда браузеру. Заголовок Content-Disposition со значением attachment сообщает, что PDF предлагается скачать как файл.
  3. Передача блоками. Каждый запрос к базе извлекает один блок. Метод проверяет его размер и записывает данные в поток ответа, не собирая всю книгу в памяти приложения.
  4. Согласованная версия. Транзакция с уровнем REPEATABLE_READ позволяет прочитать согласованный снимок данных, даже если книгу одновременно заменяют или удаляют.

После передачи данных браузер управляет сохранением файла на устройстве. Начало скачивания само по себе ещё не подтверждает, что файл сохранён полностью.
