Как работает чтение PDF

За кнопкой «Читать» работает метод read класса JavaLibraryService. Он проверяет версию книги и передаёт браузеру запрошенный фрагмент PDF. Сервер читает данные блоками, сохраняя память для других читателей.

Что происходит после нажатия «Читать»

  1. Проверка версии. Если файл заменили, читатель получает предложение открыть книгу заново. Так части разных версий не смешиваются.
  2. Выбор фрагмента. Браузер может запросить диапазон байтов через заголовок Range. Метод проверяет его границы и сообщает, какую часть файла отправляет.
  3. Передача книги. Далее метод извлекает необходимые блоки из базы и записывает их в поток ответа, не собирая весь PDF в памяти приложения.

На снимке показана верхняя часть метода. Передача блоков следует за строкой response.getOutputStream().
