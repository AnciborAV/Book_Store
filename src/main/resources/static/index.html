РЕДАКТОР МАГАЗИНА

Короткая заметка до 3000 символов. Абзацы отделяйте пустой строкой. Текст публикуется как обычный текст, без HTML. По одному названию в строке: до 8 списков по 50 символов. Новое название создаёт подборку. Без списков книга не показывается в «Выборе редакции».
Виден всем в карточке и описании книги, даже вне подборки. Чтобы убрать комментарий, очистите поле и сохраните.
