Как сайт запоминает меня

Отметка «Запомнить меня» помогает вернуться в свой аккаунт без повторного ввода пароля. Для этого механизма браузер хранит специальный токен в cookie, а не ваш пароль. В «Переплёте» запоминание входа настроено на 30 дней.

Что показывает этот код

  1. Восстановление входа. Проверку токена выполняет механизм Spring Security. Метод createSuccessfulAuthentication завершает создание объекта аутентификации и меняет идентификатор сессии.
  2. Учёт сессий. Восстановленная сессия регистрируется, чтобы приложение могло завершить её при сбросе пароля.
  3. Cookie с настройками защиты. Метод setCookie задаёт HttpOnly, ограничивая доступ JavaScript к cookie, включает Secure при защищённом соединении или соответствующей настройке и устанавливает SameSite=Lax.

Срок запоминания задаётся в другой части класса. На общем или чужом устройстве снимите отметку «Запомнить меня», а по окончании работы выйдите из аккаунта.
