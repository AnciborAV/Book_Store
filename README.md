# Book Store

Учебный REST API на Java 17, Spring Boot, PostgreSQL, Liquibase и MapStruct.

## Сборка и тесты

Нужны JDK 17 и запущенный Docker. Maven скачивается через Wrapper.
Тесты сами запускают отдельную PostgreSQL в Testcontainers; локальная база не используется.

```sh
./mvnw clean verify
```

Windows: `mvnw.cmd clean verify`. Для проверки только компиляции:
`./mvnw test-compile`.

## Запуск

Подготовьте PostgreSQL и базу `books`, задайте переменные окружения:
`DB_PASSWORD` (обязательна), `DB_USERNAME` (по умолчанию postgres),
`DB_URL` (по умолчанию jdbc:postgresql://localhost:5432/books).

```sh
./mvnw spring-boot:run
```

Liquibase применяет миграции, Hibernate проверяет соответствие модели схеме.
Существующие миграции не переписываются.

## API

- GET /books — список книг.
- GET /books/{id} — книга или 404.
- POST /books — создание, 201 и заголовок Location.

Тело создания: `{"name":"Java","author":"Author"}`.
Поля обязательны, не могут состоять из пробелов, максимум 255 символов.
Идентификатор назначает база; переданный клиентом id не используется.
Неверные данные возвращают 400, нарушение ограничений базы — 409.
Сохранено исходное правило: название книги уникально.
Это учебное ограничение, а не универсальное правило книжного каталога.

## Устройство

Controller → Service → Repository. DTO отделены от JPA-сущностей.
MapStruct преобразует запрос создания и ответ. Поля id/version/created/modified
управляются приложением и базой; публичных сеттеров для них нет.
Тесты проверяют создание, чтение, Location, валидацию, конфликты и идентичность.

## Веб-приложение «Переплёт»

После запуска откройте **http://localhost:8080/**. На странице доступны поиск по
названию и автору, добавление книг в существующий каталог, регистрация, вход,
выход и загрузка аватарки. «Моя полка» хранится в браузере на текущем устройстве.
Если каталог пуст, отображается явно обозначенная демонстрационная подборка.
Обложки — стилизованные иллюстрации, цены и оформление заказов не реализованы.

Для запуска без PostgreSQL (JDK 17):

```sh
./mvnw spring-boot:run -Dspring-boot.run.profiles=local
```

Локальный профиль сохраняет книги, пользователей и аватарки в H2 в каталоге
`data/`. Обычный запуск использует существующие настройки PostgreSQL.
Схема пользователей добавляется новой миграцией Liquibase.

Аккаунт создаётся кнопкой «Войти → Зарегистрироваться». Пароль — от 8 до 72
символов, хранится как BCrypt-хеш. В профиле загрузите PNG/JPEG до 2 МБ,
не более 4096 × 4096 пикселей. Сервер обрезает изображение по центру до квадрата,
масштабирует до 256 × 256 и сохраняет PNG в базе. Аватарка доступна только
её владельцу. После повторного входа и перезапуска она остаётся в профиле.

Новые маршруты: `GET /api/auth/csrf`, `POST /api/auth/register` (JSON),
`POST /api/auth/login` (form: email/password), `POST /api/auth/logout`,
`GET /api/profile`, `GET /api/profile/avatar`, `PUT /api/profile/avatar`
(multipart, поле `file`). Изменения `/api/**` требуют CSRF-токен из первого
маршрута и ту же сессию. Исходный публичный REST API `/books` сохранён.
Для публикации в интернете нужны HTTPS и ограничение доступа к изменению
публичного каталога в соответствии с ролями магазина.

Проверка веб-функций без Docker:

```sh
./mvnw -Dtest=ProfileControllerTest,BookMapperTest test
```

Дизайн: собственная вёрстка, книжная иллюстрация и обложки на CSS/SVG.
Визуальные ориентиры: [Dribbble](https://dribbble.com/search/book-store-website)
и [Webflow](https://webflow.com/list/bookstore). Шрифты Google Fonts загружаются
при наличии интернета; без него используются системные шрифты.
