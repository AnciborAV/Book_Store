# Переплёт · Book Store

Книжный каталог на Java 21, Spring Boot, Maven, PostgreSQL и Liquibase.
Регистрация, личный профиль с аватаркой, избранное, корзина и отзывы.
Интерфейс работает на **http://localhost:8080/**.

## Запуск в IntelliJ IDEA

1. Выберите JDK 21 для Project SDK и Maven Runner. Перезагрузите Maven-проект.
2. Для существующей PostgreSQL задайте в Run Configuration переменную
   `DB_PASSWORD` с вашим паролем. По умолчанию база `BOOKS`, пользователь `postgres`.
   При необходимости задайте `DB_URL` и `DB_USERNAME`.
3. Запустите `BookStoreDemoApplication` и откройте http://localhost:8080/.

Пароль не хранится в Git. Если прежний пароль из опубликованного файла ещё
используется, смените его в PostgreSQL и укажите новый в Run Configuration.

Для запуска **без установки PostgreSQL** укажите Active profiles: `local`.
Этот профиль использует отдельную файловую H2 в `data/bookstore`; данные сохраняются
после остановки приложения. PostgreSQL и H2 — разные базы: переключение профиля
не переносит между ними пользователей, отзывы или корзины.
Не удаляйте `data/`, если хотите сохранить данные локального профиля.

Команды из корня проекта (JDK 21):

```sh
# PostgreSQL: предварительно задайте DB_PASSWORD в окружении
./mvnw spring-boot:run
# Отдельная локальная H2
./mvnw spring-boot:run -Dspring-boot.run.profiles=local
```

Windows: используйте `mvnw.cmd`. Порт по умолчанию 8080, адрес привязки 127.0.0.1.
Сервер доступен только на вашем компьютере. `PORT` и `SERVER_ADDRESS` позволяют
явно переопределить эти значения. Если порт занят, остановите предыдущий запуск.

## Архитектура

- HTTP-контроллеры отвечают за маршруты, DTO и валидацию входа.
- Сервисы содержат бизнес-операции и границы транзакций.
- JPA-репозитории управляют книгами и аккаунтами; JDBC-репозитории — личным
  выбором и отзывами. SQL не находится в контроллерах.
- `CurrentAccount` получает пользователя по имени из защищённой сессии.
  Блокировка строки аккаунта сериализует его изменения, предотвращая дубли
  при одновременных запросах корзины, избранного и отзывов.
- `AvatarProcessor` проверяет формат и размеры изображения перед декодированием.
  Обработка изображения выполняется до открытия транзакции записи.
- `api-client.js` централизует HTTP-запросы, CSRF и обработку ошибок интерфейса.

Liquibase управляет схемой; Hibernate только проверяет её. Уже опубликованные
миграции сохранены без изменения контрольных сумм. Обновление не удаляет каталог
или пользовательские записи. Названия книг по прежнему правилу уникальны.

## Доступ и API

Чтение каталога и отзывов публичное. Создание книги требует входа и CSRF, как
изменение профиля, корзины, избранного и отзывов. В локальном приложении любой
зарегистрированный читатель может добавить книгу. Отдельной роли администратора пока нет.

- `GET /books`, `GET /books/{id}`, `POST /books`.
- `GET /api/auth/csrf`, `POST /api/auth/register`, `POST /api/auth/login`, `POST /api/auth/logout`.
- `GET /api/profile`, `GET/PUT /api/profile/avatar` (multipart, поле `file`).

Создание книги: `{"name":"Java","author":"Author","category":"Программирование"}`.
Регистрация: `{"email":"reader@example.com","displayName":"Читатель","password":"your-password"}`.
Вход использует form-поля `email` и `password`. CSRF-токен получается до регистрации
или входа, передаётся заголовком из `headerName` с той же cookie сессии и обновляется
после входа. Пароль: минимум 8 символов, максимум 72 байта UTF-8 (ограничение BCrypt).
Аватарка: PNG/JPEG до 2 МБ и 4096×4096; сохраняется PNG 256×256, доступна владельцу.

## Проверка

```sh
# Все тесты, включая PostgreSQL через Testcontainers. Нужен Docker.
./mvnw clean verify
# Контракт HTTP и параллельные изменения на H2, без Docker
./mvnw -Dtest=BookMapperTest,ProfileControllerTest,CatalogTest,SelectionTest,MutationSafetyTest test
```

GitHub Actions проверяет обе базы, затем запускает собранный JAR на порту 8080
и Chromium. Браузерный сценарий проверяет регистрацию, создание книги, корзину,
избранное, отзыв и их сохранность после полного перезапуска сервера с той же
файловой H2. Адаптер `LowercaseH2Database` согласует имена таблиц Liquibase
с существующим режимом H2 `DATABASE_TO_LOWER=TRUE`, сохраняя файлы и историю миграций.
Снимки интерфейса при ширине 1440 и 390 пикселей и журналы доступны
в артефакте `test-report`. Локально сценарий можно запустить после `./mvnw package`,
установив Playwright 1.58.2 и Chromium: `node scripts/browser-smoke.cjs`.

## Каталог, корзина и отзывы

Каталог пополняется при старте миграцией `catalog.xml`: пять разделов по 50
библиографических позиций — российские и зарубежные авторы, история, философия,
гражданское право. Это редакционная подборка, а не объективный рейтинг продаж.
Многотомные издания учитываются как одна позиция. В правовом разделе есть
исторические труды; год и актуальность конкретного издания следует проверять отдельно.
Существующие записи не удаляются и не перезаписываются: при совпадении названия
новая запись не создаётся, категория присваивается только при совпадении автора.

Интерфейс поддерживает поиск, категории со счётчиками, сортировку, просмотр по 12
книг, избранное, карточку книги и корзину. После входа избранное сохраняется в
`user_favorites`, корзина — в `cart_items` с количеством 1–99 экземпляров. Каждая
запись связана с пользователем из `store_users` и книгой из общего каталога `books`.
Таблицы личного выбора изначально пусты и пополняются только действиями пользователя.
Выбор доступен после повторного входа и с другого устройства. Удаление из корзины
или избранного не удаляет книгу из каталога. Гостевой выбор остаётся в localStorage
этого браузера и не переносится автоматически в аккаунт; после выхода он восстанавливается. Цены, наличие,
доставка и приём платежей пока не подключены; корзина служит списком выбора.

Отзывы хранятся в базе. Читать их можно без входа; оставлять, изменять и удалять
свои — после авторизации. На книгу разрешён один отзыв от пользователя, оценка
1–5 и текст до 2000 символов. Изменяющие запросы требуют CSRF. API:
`GET /api/books/{id}/reviews`, `PUT /api/books/{id}/reviews` с JSON
`{"rating":5,"body":"Мои впечатления"}`, `DELETE /api/books/{id}/reviews/{reviewId}`.

Обложки — собственные векторные иллюстрации каталога с названиями и авторами,
а не фотографии конкретных издательских изданий. Работают без внешнего сервиса.
Список позиций: `src/main/resources/db/migration/catalog-books.csv`.

Ориентиры подбора и библиографической проверки:
[подборка мировой классики издательства «Эксмо»](https://eksmo.ru/selections/100-luchshikh-knig-vsekh-vremen-ID15590178/),
[каталог РГБ — Российское гражданское право](https://search.rsl.ru/ru/record/01004561685),
[труды Б. Б. Черепахина](https://civil.consultant.ru/elib/books/22/),
[курс НИУ ВШЭ о вещном праве](https://id.hse.ru/edu/courses/835250848).

Проверка новых функций без Docker:

```sh
./mvnw -Dtest=SelectionTest,CatalogTest,ProfileControllerTest,BookMapperTest test
```

Для запуска используйте JDK 21 (как указано в `pom.xml`). Перезапустите приложение,
чтобы применились новые миграции, и обновите страницу браузера.


Личный выбор (все маршруты требуют входа; изменения — CSRF):
`GET /api/selection`, `PUT/DELETE /api/selection/favorites/{bookId}`,
`PUT /api/selection/cart/{bookId}` с JSON `{"quantity":2}`,
`DELETE /api/selection/cart/{bookId}`, `DELETE /api/selection/cart`.
Идентификатор пользователя берётся из сессии: передать чужой `user_id` нельзя.
Миграция `user-selection.xml` добавляет таблицы без удаления существующего каталога.
