# Book Store

Учебный REST API на Java 21, Spring Boot, PostgreSQL, Liquibase и MapStruct.

## Сборка и тесты

Нужны JDK 21 и запущенный Docker. Maven скачивается через Wrapper.
Тесты сами запускают отдельную PostgreSQL в Testcontainers; локальная база не используется.

```sh
./mvnw clean verify
```

Windows: `mvnw.cmd clean verify`. Для проверки только компиляции:
`./mvnw test-compile`.

## Запуск

Подготовьте PostgreSQL и базу `books`, задайте переменные окружения:
`DB_PASSWORD` (обязательна), `DB_USERNAME` (по умолчанию postgres),
`DB_URL` (по умолчанию jdbc:postgresql://localhost:5432/books).

```sh
./mvnw spring-boot:run
```

Liquibase применяет миграции, Hibernate проверяет соответствие модели схеме.
Существующие миграции не переписываются.

## API

- GET /books — список книг.
- GET /books/{id} — книга или 404.
- POST /books — создание, 201 и заголовок Location.

Тело создания: `{"name":"Java","author":"Author"}`.
Поля обязательны, не могут состоять из пробелов, максимум 255 символов.
Идентификатор назначает база; переданный клиентом id не используется.
Неверные данные возвращают 400, нарушение ограничений базы — 409.
Сохранено исходное правило: название книги уникально.
Это учебное ограничение, а не универсальное правило книжного каталога.

## Устройство

Controller → Service → Repository. DTO отделены от JPA-сущностей.
MapStruct преобразует запрос создания и ответ. Поля id/version/created/modified
управляются приложением и базой; публичных сеттеров для них нет.
Тесты проверяют создание, чтение, Location, валидацию, конфликты и идентичность.

## Веб-приложение «Переплёт»

После запуска откройте **http://localhost:8080/**. На странице доступны поиск по
названию и автору, добавление книг в существующий каталог, регистрация, вход,
выход и загрузка аватарки. «Моя полка» и корзина сохраняются в аккаунте после входа; гостевой выбор хранится отдельно в браузере.
Если каталог пуст, отображается явно обозначенная демонстрационная подборка.
Обложки — стилизованные иллюстрации, цены и оформление заказов не реализованы.

Для запуска без PostgreSQL (JDK 21):

```sh
./mvnw spring-boot:run -Dspring-boot.run.profiles=local
```

Локальный профиль сохраняет книги, пользователей и аватарки в H2 в каталоге
`data/`. Обычный запуск использует существующие настройки PostgreSQL.
Схема пользователей добавляется новой миграцией Liquibase.

Аккаунт создаётся кнопкой «Войти → Зарегистрироваться». Пароль — от 8 до 72
символов, хранится как BCrypt-хеш. В профиле загрузите PNG/JPEG до 2 МБ,
не более 4096 × 4096 пикселей. Сервер обрезает изображение по центру до квадрата,
масштабирует до 256 × 256 и сохраняет PNG в базе. Аватарка доступна только
её владельцу. После повторного входа и перезапуска она остаётся в профиле.

Новые маршруты: `GET /api/auth/csrf`, `POST /api/auth/register` (JSON),
`POST /api/auth/login` (form: email/password), `POST /api/auth/logout`,
`GET /api/profile`, `GET /api/profile/avatar`, `PUT /api/profile/avatar`
(multipart, поле `file`). Изменения `/api/**` требуют CSRF-токен из первого
маршрута и ту же сессию. Исходный публичный REST API `/books` сохранён.
Для публикации в интернете нужны HTTPS и ограничение доступа к изменению
публичного каталога в соответствии с ролями магазина.

Проверка веб-функций без Docker:

```sh
./mvnw -Dtest=ProfileControllerTest,BookMapperTest test
```

Дизайн: собственная вёрстка, книжная иллюстрация и обложки на CSS/SVG.
Визуальные ориентиры: [Dribbble](https://dribbble.com/search/book-store-website)
и [Webflow](https://webflow.com/list/bookstore). Шрифты Google Fonts загружаются
при наличии интернета; без него используются системные шрифты.


## Каталог, корзина и отзывы

Каталог пополняется при старте миграцией `catalog.xml`: пять разделов по 50
библиографических позиций — российские и зарубежные авторы, история, философия,
гражданское право. Это редакционная подборка, а не объективный рейтинг продаж.
Многотомные издания учитываются как одна позиция. В правовом разделе есть
исторические труды; год и актуальность конкретного издания следует проверять отдельно.
Существующие записи не удаляются и не перезаписываются: при совпадении названия
новая запись не создаётся, категория присваивается только при совпадении автора.

Интерфейс поддерживает поиск, категории со счётчиками, сортировку, просмотр по 12
книг, избранное, карточку книги и корзину. После входа избранное сохраняется в
`user_favorites`, корзина — в `cart_items` с количеством 1–99 экземпляров. Каждая
запись связана с пользователем из `store_users` и книгой из общего каталога `books`.
Таблицы личного выбора изначально пусты и пополняются только действиями пользователя.
Выбор доступен после повторного входа и с другого устройства. Удаление из корзины
или избранного не удаляет книгу из каталога. Гостевой выбор остаётся в localStorage
этого браузера и не переносится автоматически в аккаунт; после выхода он восстанавливается. Цены, наличие,
доставка и приём платежей пока не подключены; корзина служит списком выбора.

Отзывы хранятся в базе. Читать их можно без входа; оставлять, изменять и удалять
свои — после авторизации. На книгу разрешён один отзыв от пользователя, оценка
1–5 и текст до 2000 символов. Изменяющие запросы требуют CSRF. API:
`GET /api/books/{id}/reviews`, `PUT /api/books/{id}/reviews` с JSON
`{"rating":5,"body":"Мои впечатления"}`, `DELETE /api/books/{id}/reviews/{reviewId}`.

Обложки — собственные векторные иллюстрации каталога с названиями и авторами,
а не фотографии конкретных издательских изданий. Работают без внешнего сервиса.
Список позиций: `src/main/resources/db/migration/catalog-books.csv`.

Ориентиры подбора и библиографической проверки:
[подборка мировой классики издательства «Эксмо»](https://eksmo.ru/selections/100-luchshikh-knig-vsekh-vremen-ID15590178/),
[каталог РГБ — Российское гражданское право](https://search.rsl.ru/ru/record/01004561685),
[труды Б. Б. Черепахина](https://civil.consultant.ru/elib/books/22/),
[курс НИУ ВШЭ о вещном праве](https://id.hse.ru/edu/courses/835250848).

Проверка новых функций без Docker:

```sh
./mvnw -Dtest=SelectionTest,CatalogTest,ProfileControllerTest,BookMapperTest test
```

Для запуска используйте JDK 21 (как указано в `pom.xml`). Перезапустите приложение,
чтобы применились новые миграции, и обновите страницу браузера.


Личный выбор (все маршруты требуют входа; изменения — CSRF):
`GET /api/selection`, `PUT/DELETE /api/selection/favorites/{bookId}`,
`PUT /api/selection/cart/{bookId}` с JSON `{"quantity":2}`,
`DELETE /api/selection/cart/{bookId}`, `DELETE /api/selection/cart`.
Идентификатор пользователя берётся из сессии: передать чужой `user_id` нельзя.
Миграция `user-selection.xml` добавляет таблицы без удаления существующего каталога.
