## Принятые правила и границы

- UTF-8/LF, завершающий перевод строки, пробелы для отступов; MJS/YAML включены в .editorconfig. Существующие тестовые фикстуры не переписывались только ради косметики.
- Читаемые методы и параметры, явные импорты собственного Java-кода, блоки условий, сохранение порядка полей/аннотаций/операций. Для строк, SQL, шаблонов и данных точность важнее условного лимита длины строки.
- В JS сохранены значения строк и исходные способы кавычек; массовая замена кавычек не выполнялась. Проверялись синтаксические деревья и порядок await. Общая структура и читаемость унифицированы без утверждения о строгом автоматическом форматировании каждой строки.
- В CSS сохранены каскад, значения, селекторы и медиазапросы; визуальная проверка и CSSOM обязательны. В HTML сохранены значимые пробелы и DOM. Ошибка пробела в псевдоклассах выявлена и исправлена визуальным CI в PR №122.
- API, DTO, данные, права, CSRF, remember-me, версии, блокировки, денежные типы, миграции и Java 21 сохранены. Новые зависимости приложения не добавлялись и версии массово не обновлялись.

## Финальная проверка

Подтверждённый функциональный код: `a369482fec74cd4adff67c9e586b1dbed49d0997`.

- [Полный CI](https://github.com/AnciborAV/Book_Store/actions/runs/41308475194): 186 Java-тестов без ошибок/отказов/пропусков, включая PostgreSQL; все 17 клиентских наборов, три Python-валидатора, оба браузерных сценария и Docker-сборка Java 21.
- [Визуальный CI](https://github.com/AnciborAV/Book_Store/actions/runs/41308475245): 14 статических страниц × 390/1440, 28 попиксельно совпавших пар, 22 совпавших CSSOM. Скрипты приложения отключены, динамические действия проверяются отдельными e2e.
- Закрывающий PR содержит только документы; на его итоговом SHA запускается стандартный полный CI. Точная ссылка и результат указываются в описании PR после завершения.

Рабочая база, реальные заказы и реальная отправка писем для проверок не использовались.

## Что не является незавершённым рефакторингом

Независимый аудит безопасности/зависимостей, нагрузочные испытания, проверка резервного восстановления и мониторинга рабочего сервера, отдельная доступность/WCAG и матрица Safari/Firefox относятся к последующим задачам качества, а не к открытым строкам данного цикла. Финальный отчёт не утверждает универсального соответствия всем возможным профессиональным требованиям или отсутствия будущих дефектов.
