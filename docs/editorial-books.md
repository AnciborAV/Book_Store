# Подборки и описания книг

После обновления сайта войдите как администратор и откройте **Выбор редакции → Управлять подборками**. Поиск охватывает бумажный каталог и PDF разделов Java и Гражданское право.

У книги нажмите **Редактировать подборки**:
- В поле «Подборки редактора» укажите названия по одному в строке. Одна книга может входить в несколько списков (до восьми). Новое название создаёт подборку; существующие названия доступны кнопками.
- Пустое поле списков исключает книгу из рекомендаций, но оставляет её в основном каталоге.
- «Закреплённый комментарий редактора» виден всем в карточке и описании, включая книги вне подборок. Пустое поле удаляет комментарий.
- Кнопка «Сохранить и опубликовать» сохраняет данные в БД; они доступны с других устройств после обновления страницы.

В каждой карточке обоих каталогов есть кнопка **Описание**. Если текст ещё не задан, посетитель увидит понятное сообщение. Администратор может заполнить описание через эту кнопку или редактор подборки. В форме изменения PDF редактируются название, автор и файлы; описание существующей книги редактируется через общий редактор.

Первые описания подготовлены своими словами для «Философии Java» Брюса Эккеля и «Java. Полного руководства» Герберта Шилдта. Они сопоставляются по названию и автору, без зависимости от идентификаторов конкретной базы. Индивидуальная редакторская правка имеет приоритет, даже если текст очищен. Ссылка на источник сохраняется при неизменённом тексте, при собственной редакции убирается.

Источники, просмотрены 29.10.2026:
- Питер: https://www.piter.com/collection/A20271/product/filosofiya-java-4-e-polnoe-izd
- Диалектика-Вильямс: https://www.williamspublishing.com/Books/978-5-907458-86-4.html

Никакие книги автоматически не добавляются в рекомендации. Комментарии от имени владельца не создаются.

## Хранение и права

Миграция Liquibase `editorial-books-v1` добавляет таблицу `book_editorial`. Внешние ключи привязаны к книгам каталогов; при удалении книги её редакционные данные удаляются каскадно. Названия списков хранятся строками, переносы внутри названия запрещены. Описания до 3000 символов, комментарии до 1000.

Публичные GET: `/api/editorial/books` (по умолчанию только рекомендации), `/api/editorial/books?recommended=false` (полный индекс), `/api/editorial/books/{catalog|library}/{id}`. PUT `/api/admin/editorial/books/{kind}/{id}` доступен только ADMIN с CSRF. Версия и блокировка родительской книги защищают от перезаписи параллельной правки. В интерфейсе текст вставляется через textContent, без выполнения HTML.

Тексты заметок короткие, в пределах объёма одной печатной страницы. На телефоне окно прокручивается, чтобы не уменьшать шрифт ради размещения всего текста на одном экране.
