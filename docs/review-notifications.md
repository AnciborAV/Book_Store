# Отзывы и SMTP-уведомления

В профиле администратора кнопка «Отзывы и уведомления» открывает общий список книжных отзывов (20 на страницу), фильтр непрочитанных и переход к отзывам о сайте. Редактирование книжного отзыва снова помечает его непрочитанным, но не отправляет повторное письмо.

Новые книжные отзывы и сообщения о сайте сохраняются вместе с записью в почтовой очереди в одной транзакции. Включая сообщения, для которых пользователь не разрешил публичную публикацию: они доступны только администратору и получателям уведомлений. Старые отзывы автоматически в очередь не добавляются. Повторная отправка той же формы отзыва о сайте не создаёт повторного письма.

## Render → book-store → Environment

Для платного веб-сервиса доступны исходящие SMTP-порты. Укажите параметры своего провайдера:

| Переменная | Значение |
|---|---|
| BOOKSTORE_REVIEW_MAIL_ENABLED | true |
| REVIEW_MAIL_TO | рабочий и личный адрес через запятую |
| MAIL_HOST | SMTP-сервер провайдера |
| MAIL_PORT | 587 для STARTTLS либо 465 для SSL |
| MAIL_USERNAME | логин почтового ящика |
| MAIL_PASSWORD | пароль приложения или SMTP-пароль |
| MAIL_FROM | разрешённый провайдером адрес отправителя |
| MAIL_AUTH | true |
| MAIL_STARTTLS | true для 587, false для 465 |
| MAIL_SSL | false для 587, true для 465 |

Не изменяйте HTTP-переменную PORT. Не сохраняйте пароли в GitHub. REVIEW_MAIL_FROM необязательно переопределяет MAIL_FROM. Если REVIEW_MAIL_TO не задан, используется существующий BOOKSTORE_ADMIN_EMAIL. Его изменение для выбора получателей не требуется. Эти SMTP-параметры также используются существующими уведомлениями о заказах; их отдельный переключатель BOOKSTORE_MAIL_ENABLED не меняется.

Очередь проверяется каждые 15 секунд; недоступность почты не отменяет сохранение отзыва. До пяти попыток с интервалом не менее 10 минут. После последней попытки и окончания интервала повтор можно запустить из панели администратора. При выключенной отправке очередь накапливается и будет отправлена после включения.

SMTP не гарантирует отсутствие дубликатов: если сервер принял письмо, но соединение оборвалось до подтверждения (или принял лишь часть получателей), повторная попытка может продублировать письмо. Статус отправки означает принятие SMTP-сервером, а не подтверждённую доставку в ящик.

После настройки оставьте новый тестовый отзыв о книге и сообщение о сайте. Проверьте оба ящика и «Спам», затем состояние очереди в панели администратора. Без реальных настроек провайдера доставку проверить нельзя. Подключение почты к ChatGPT не настраивает SMTP приложения автоматически.
