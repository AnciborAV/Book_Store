# Обложки каталога

Для 219 из 250 книг подключены реальные обложки. Файлы хранятся локально: каталог не зависит от доступности внешних сайтов. Обложки «Войны и мира» и «Маленького принца», а также фотография читального кабинета предоставлены владельцем проекта.

Источники остальных изображений перечислены в `book-cover-sources.json`. Обложка иллюстрирует произведение: каталог не содержит ISBN, поэтому конкретное издание, перевод или комплект томов может отличаться. Перед коммерческой публикацией необходимо согласовать использование изображений с правообладателями.
