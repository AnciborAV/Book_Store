# Восстановление пароля

Вход → «Забыли пароль?» → адрес зарегистрированного пользователя → письмо с одноразовой ссылкой → новый пароль и его подтверждение → вход с новым паролем.

Используется существующий SMTP: MAIL_HOST, MAIL_PORT, MAIL_USERNAME, MAIL_PASSWORD,
MAIL_AUTH, MAIL_SSL, MAIL_STARTTLS. Отправитель — REVIEW_MAIL_FROM (или MAIL_FROM).
Для Mail.ru используйте пароль приложения, а не пароль от почтового ящика.
Администраторские REVIEW_MAIL_TO и BOOKSTORE_REVIEW_MAIL_ENABLED не управляют письмами восстановления: письмо направляется владельцу аккаунта.

Адрес ссылок задаёт bookstore.public-url (SPRING-конфигурация); по умолчанию
https://book-store-cgvx.onrender.com. При смене домена задайте BOOKSTORE_PUBLIC_URL.

Ссылки действуют 30 минут, применяются однократно. В БД хранится SHA-256 токена;
новая ссылка заменяет старую. Токен в адресной строке расположен после # и сразу
удаляется из истории текущего адреса. Пароли хранятся через BCrypt.
Несовпадение подтверждения не расходует ссылку. Запрос требует CSRF.
Ответ запроса письма одинаков для существующего и неизвестного адреса.
Ограничение: один запрос на адрес в минуту и 30 запросов в минуту на экземпляр.
Отправка асинхронная, очередь ограничена 30 задачами; перезапуск может потерять
ожидающие письма — пользователь может запросить ссылку повторно.
После смены пароля завершаются зарегистрированные сеансы этого экземпляра приложения.
Для нескольких экземпляров потребуется общая система отзыва сеансов.

Глаз доступен для входа, регистрации, нового пароля и подтверждения.
Повторное нажатие скрывает пароль. Закрытие окна, сброс формы, смена режима
и уход со вкладки также скрывают его. Кнопка доступна с клавиатуры и имеет
изменяющуюся подпись для экранного диктора.

Проверка перед публикацией: PasswordRecoveryTest и ProfileControllerTest.
После развёртывания запросить письмо для своего аккаунта, пройти ссылку,
сменить пароль и проверить повторное использование ссылки и старый пароль.
Реальная доставка SMTP зависит от настроек Render и провайдера почты.
