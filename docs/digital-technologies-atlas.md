# Современные цифровые технологии

Новый управляемый книжный раздел создаётся миграцией `digital-technologies-section.xml`. Администратор добавляет книги через существующую панель каталога: можно сначала загрузить обложку, а позже добавить PDF. Миграция не заполняет раздел демонстрационными книгами и не дублирует раздел с тем же названием, созданный вручную.

Рядом с «Все книги» и «Моя полка» появляется «Атлас современных цифровых технологий». Ссылка определяется по стабильному ID либо каноническому названию. Возврат `/index.html#digital-books` выбирает соответствующий раздел после загрузки каталога.

## Атлас

Восемь направлений соответствуют предоставленной справке: данные, искусственный интеллект, облако, интернет и 5G, блокчейн, кибербезопасность, квантовые технологии, пользовательский опыт. Более 3500 слов основного материала включают устройство технологий, применение, словарь, учебные примеры, ограничения и направления развития. AI представлен обзорно и связан с пятью существующими материалами.

Первичные источники перечислены непосредственно в главах: NIST, IETF, ITU, W3C, документация разработчиков, исследовательские организации. Обзор не является рейтингом продуктов; перспективы не содержат обещаний сроков. Учебные сценарии не описывают реальную архитектуру действующего магазина.

Девять оригинальных SVG-иллюстраций суммарно занимают около 14 КБ. Они локальны и не требуют внешних сервисов или шрифтов. В атласе есть смена трёх сценариев и сравнение ответственности в IaaS/PaaS/SaaS. Весь основной текст и ссылки доступны без JavaScript. Проза выровнена по ширине, первая строка абзаца имеет отступ, длинные тире не используются.

`digital-atlas-data.js` содержит редакционный источник; `scripts/build-digital-atlas.py` воспроизводит HTML и SVG без сторонних Python-пакетов. После изменения источника запустите генератор, затем `node scripts/test-digital-atlas.mjs`. Пять статических ресурсов разрешены для анонимного GET; X-Frame-Options DENY сохранён.

## Комментарий редактора

Ограничение 1000 знаков снято в форме и DTO. Новая миграция `editorial-comment-text.xml` меняет только тип `book_editorial.comment` на TEXT, сохраняя значения и пустое значение по умолчанию. Поле ввода увеличено до десяти строк. Старые миграции не меняются. Ограничения описания и названий подборок не затрагиваются.

## Проверки

97 серверных тестов без ошибок: основной набор 94 теста и три дополнительных теста миграций. Проверены публичные ресурсы, создание книги с обложкой и последующим PDF в новом разделе, сохранение и редактирование комментария более 13 тысяч знаков для обычной книги и PDF, сохранение старого текста и DEFAULT, отсутствие дубля ручного раздела.

Миграции локально проверены на H2 в режиме PostgreSQL. Отдельного запуска PostgreSQL-контейнера не выполнялось.

Прошли Node-проверки цифрового атласа, литературных атласов и навигации AI. В браузере проверены выбор раздела, обратная ссылка, сценарии, переключение моделей облака, изображения и мобильная ширина. Горизонтального переполнения на мобильной ширине нет; ошибок JavaScript не обнаружено.
