# Расстановка книг администратором

Войдите как администратор и нажмите «Расставить книги ↔» над каталогом. Выберите все книги или раздел. Перетащите карточку на место другой; на телефоне и с клавиатуры используйте «Раньше» / «Позже». Нажмите «Сохранить порядок». Посетители видят его при сортировке «Порядок магазина».

Полка содержит весь раздел без поиска и пагинации. Порядок общий для каталога: перестановка внутри раздела меняет только занятые этим разделом места, сохраняя относительный порядок остальных книг. Новые книги идут после ранее расставленных. Назначение цены отдельной PDF-книге сохраняет её место.

Правки до сохранения локальны. «Отменить правки» возвращает исходную полку; закрытие с изменениями требует подтверждения. При конфликте с другим администратором сохранение отклоняется: обновите полку и повторите расстановку.

API: `PUT /api/admin/catalogue/order` с `{version, books:[{kind,id}]}`. Требуются ADMIN и CSRF. Сервер проверяет полную актуальную совокупность карточек и версию, сохраняет атомарно. Версия и книги читаются одним снимком. Операции изменения состава каталога используют ту же блокировку состояния.

Проверка: 39 тестов CatalogueOrderTest, CatalogueManagementTest, JavaLibraryTest, CommerceTest, SelectionTest, EditorialTest; `scripts/test-book-ordering.mjs` проверяет перетаскивание, кнопки, сохранение, отмену, конфликты и выход из аккаунта. Локальный визуальный запуск браузера недоступен в среде проверки.
