# Описания раздела Java

Проверено 29 октября 2026 года по публичному каталогу: 24 книги, из них 22 без описания.
Новые тексты - самостоятельные редакционные аннотации по материалам авторов и издательств, без заимствования их рекламных формулировок.

Тексты «Философии Java» и «Java. Полное руководство (12 издание)» сохранены без изменений. Новые аннотации заполняют только отсутствующие описания. Сохранённый текст администратора, включая намеренно пустое описание, имеет приоритет. Исходное непустое описание PDF также сохраняется. Комментарии и подборки не меняются.

Номер издания загруженного PDF нельзя установить только по названию. Описания раскрывают общую направленность книг и не приписывают файлам версию с актуальной страницы издательства. Для Spring in Action отдельно указан номер издания источника. Имена и названия в ключах соответствуют каталогу, включая существующие опечатки: метаданные книг этим PR не исправляются.

## Проверка

Снимок названий 24 Java-книг хранится в тестовых ресурсах. Тест проверяет полноту описаний, точное совпадение двух защищённых текстов, отсутствие длинных тире в новых текстах и корректность ссылок. Интеграционный тест проверяет приоритет пользовательских описаний и сохранность комментариев. Новые тексты не записываются поверх данных в PostgreSQL; они поставляются как ресурс приложения и доступны через существующий API описаний.
