# Отзывы о сайте

Внизу главной страницы — «Ваше мнение важно»; ссылка есть в подвале.
Автор входит в аккаунт, выбирает отзыв/замечание/предложение и пишет до 3000 символов.
Имя берётся из аккаунта, подставить чужого автора через API нельзя.
Сообщение сохраняется в PostgreSQL; перезапуск приложения его не удаляет.
Повтор отправки с тем же requestId не создаёт дубликат. Новое сообщение — не чаще раза в минуту на аккаунт.

По умолчанию сообщение доступно только администратору. Автор может разрешить публичную публикацию.
После входа ADMIN внизу страницы появляется блок «Сообщения администратору».
Нажмите «Обновить сообщения»: новые сообщения можно опубликовать при наличии согласия либо перенести в архив.
Опубликованное сообщение можно снять с публикации; архивное — вернуть в новые.
Публикация не редактирует текст автора. Публичный API не возвращает почту, идентификатор аккаунта и закрытые сообщения.
Списки разбиты на страницы по 20 сообщений. Проверки роли, CSRF и согласия выполняются на сервере.

## Электронная почта
В этой версии уведомления по почте не отправляются. Это согласованный запасной вариант — отзывы на сайте.
Подключение Gmail к ChatGPT не выдаёт серверу сайта права отправки писем.
Render Free блокирует исходящие SMTP-порты 25/465/587 (https://render.com/docs/free).
Для уведомлений нужен отдельный почтовый HTTP API, подтверждённый отправитель и секрет в Environment Render.
Существующие настройки писем о заказах не меняются. Новых платных сервисов не подключено.

## Отметка скачивания Java PDF
После нажатия кнопка становится зелёной и показывает «Скачать ещё раз».
История хранится локально в браузере, отдельно для гостя и каждого вошедшего аккаунта.
Это факт запуска скачивания, а не подтверждение записи файла на диск. Есть кнопка сброса отметки.
На другом устройстве отметки не появятся; очистка данных браузера их удаляет.
PDF передаётся обычной ссылкой без загрузки большого файла в память JavaScript.
