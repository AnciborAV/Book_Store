# Атлас языков программирования

В разделе Java ссылка рядом с «Моей полкой» открывает `/programming-atlas.html`. Атлас доступен без регистрации; разрешение на iframe не добавлялось. Три литературных атласа сохраняют свои адреса и получают ссылку на новый.

## Содержание и источники

37 карточек: 35 языков, машинный код и семейство ассемблеров. История начинается с Лавлейс, Тьюринга, Plankalkül, Manchester Baby и EDSAC. Архивный фрагмент EDSAC датирован июнем 1949 года, а не первым запуском 6 мая. Источники включают архив Кембриджа, Манчестерский университет, архив Цузе, Science Museum, IBM, работу Маккарти, отчёт ALGOL 60 и документацию разработчиков языков. Ссылки доступны в карточках и в сворачиваемом списке.

Даты обозначают конкретные вехи, а не единый критерий рождения языка. Диалект указан у каждого примера: в частности, Common Lisp не выдаётся за синтаксис 1958 года. MOS 6502 относится к 1975 году. Демонстрация исполняет только фиксированные шесть команд; BRK останавливает учебную модель, но на настоящем процессоре вызывает прерывание. Стек и обработчик не моделируются.

Сравнение предлагает девять вариантов суммы квадратов от 1 до 5, включая Lisp и объектную модель Java 21. Это сравнение способов выражения задачи, а не производительности. Перспективы отделены от существующих возможностей; рейтинги популярности и неподтверждённые сроки выпуска не используются. Текст выровнен по ширине с отступом первой строки; код сохраняет пробелы и левое выравнивание.

## Проверка

- `node scripts/test-reading-atlases.mjs`
- `node scripts/test-programming-atlas.mjs --export`
- 92 серверных теста: 0 ошибок, включая анонимный GET пяти новых ресурсов и сохранение X-Frame-Options DENY.
- Реально скомпилированы и запущены три примера Java 21, C99, C++17; выполнены Python 3 и JavaScript. Все семь вернули 55. Остальные диалекты прошли редакционную проверку, но их среды выполнения локально не устанавливались.
- Браузер: поиск, карточка Java, шесть шагов 6502, переключение сравнения; проверены широкая и мобильная ширина. Горизонтального переполнения страницы на мобильной ширине нет; ошибок JavaScript не обнаружено.

Дополнительные изображения, внешние библиотеки и сетевой запуск кода не нужны. Новый текст и интерактивность поставляются статическими файлами, без изменений базы и книжных описаний.
