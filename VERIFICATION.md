# Проверка рефакторинга — 27 октября 2026

## Состав проверок

- BookMapperTest: маппинг и идентичность новых JPA-сущностей.
- BookControllerTest: PostgreSQL, создание/чтение, валидация, конфликты, Location.
- ProfileControllerTest / ProfilePostgresTest: H2 и PostgreSQL, регистрация,
  BCrypt, CSRF, неверный пароль, аватарка, повторная сессия, выход.
- ShelfControllerTest / ShelfPostgresTest: H2 и PostgreSQL, изоляция владельцев,
  повторное добавление, удаление, поиск, ограничения страниц и защита изменений.
- scripts/browser-smoke.cjs: реальный JAR, регистрация и вход через интерфейс,
  книга и полка, сохранение после перезапуска файловой H2, новый браузерный
  контекст, выход, отсутствие горизонтального переполнения на 1440 и 390 px.

## Воспроизводимость

GitHub Actions выполняет `./mvnw clean verify` на JDK 17, затем браузерную проверку.
В артефакте `verification` сохраняются Surefire XML, снимки экрана и журнал сервера.
Локальная среда редактора не разрешала Maven Central и не имела установленного
Chromium, поэтому полный запуск вынесен в CI. Синтаксис JS проверен через
`node --check`, пробельные ошибки — через `git diff --check`.

Нагрузочная проверка и аудит готовности к публичному размещению не выполнялись.
Java 25 не является заявленной средой этой версии: сохранён JDK 17 из pom.xml.
